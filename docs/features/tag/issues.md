## 이슈 1: 노트 태그 데이터 모델 추가 및 입력/저장/표시 MVP

### 설명

태그 기능의 MVP 슬라이스. 데이터 모델부터 UI까지 전 계층을 한 번에 깔아 사용자가 "태그를 추가하고 저장해서 다시 확인할 수 있다"는 최소 가치를 전달한다.

- `Note` 타입에 `tags: string[]` 필드 추가
- `NotesContext.createNote` 시그니처를 확장해 `tags`를 함께 전송
- `src/hooks/useTagInput.ts` 신규 생성 — `{ tags, addTag, removeTag, reset }` 반환. 이 이슈에서는 **trim 후 빈 문자열 무시** 검증만 포함
- `NoteEditor`에 태그 입력 필드(Enter로 추가) + 칩 목록(읽기 전용) 추가
- 노트 선택이 바뀌면 `reset(selectedNote.tags)`로 훅 상태 초기화
- `db.json` 기존 노트에 빈 `tags: []` 채워넣기 (선택)

### 완료 조건 (Acceptance Criteria)

**시나리오 1: 태그 추가 후 저장**
- **Given** 사용자가 노트 편집 화면을 열고 있고
- **When** 태그 입력 필드에 "react"를 입력하고 Enter를 누른 뒤 저장 버튼을 클릭하면
- **Then** 노트가 `tags: ["react"]`로 서버에 저장되고, 다시 그 노트를 선택했을 때 "react" 칩이 화면에 표시된다

**시나리오 2: 공백 전용 입력은 무시된다**
- **Given** 사용자가 태그 입력 필드에 포커스해 있고
- **When** "   " (공백만)을 입력하고 Enter를 누르면
- **Then** 칩 목록에 아무것도 추가되지 않고 입력 필드만 비워진다

**시나리오 3: 다른 노트 선택 시 태그 상태가 초기화된다**
- **Given** 노트 A의 태그 `["work", "todo"]`가 편집 화면에 표시되고 있고
- **When** 사용자가 사이드바에서 노트 B를 선택하면
- **Then** 편집 화면의 칩 목록이 노트 B의 `tags` 값으로 즉시 교체된다 (A의 잔여 태그가 보이지 않음)

**시나리오 4: 기존 태그가 있는 노트에 새 태그를 추가한다**
- **Given** 노트에 `["react"]` 태그가 표시되고 있고
- **When** 사용자가 "typescript"를 입력하고 Enter를 누른 뒤 저장 버튼을 클릭하면
- **Then** 노트가 `tags: ["react", "typescript"]`로 저장되고, 다시 노트를 선택했을 때 두 칩이 입력 순서대로 표시된다

### 변경 파일

- `src/types/note.ts` (수정)
- `src/api/notes.ts` (필요 시 시그니처 점검)
- `src/context/NotesContext.tsx` (수정)
- `src/hooks/useTagInput.ts` (신규)
- `src/components/NoteEditor.tsx` (수정)
- `db.json` (기존 노트에 `tags: []` 추가, 선택)

## 이슈 2: 칩의 × 버튼으로 태그 즉시 제거

### 설명

추가된 태그를 사용자가 즉시 되돌릴 수 있도록 칩에 `×` 버튼을 붙인다. 제거는 로컬 상태에만 반영되며, 저장 버튼 클릭 시 비로소 서버에 반영된다 (ADR-3.1). `removeTag`는 이슈 1에서 이미 훅에 정의되어 있으므로 본 이슈는 **UI 와이어링**에 집중한다.

### 완료 조건 (Acceptance Criteria)

**시나리오 1: 칩 제거 후 저장**
- **Given** 노트에 `["react", "typescript"]` 태그가 표시되고 있고
- **When** 사용자가 "react" 칩의 `×` 버튼을 클릭하고 저장 버튼을 누르면
- **Then** 서버에 `tags: ["typescript"]`만 저장되고 다시 노트를 열었을 때 "react" 칩이 보이지 않는다

**시나리오 2: 저장 전 제거는 서버에 반영되지 않는다**
- **Given** 노트에 `["react", "typescript"]` 태그가 있고
- **When** 사용자가 "react" 칩의 `×` 버튼을 클릭한 뒤 저장 버튼을 누르지 않고 다른 노트를 선택했다가 돌아오면
- **Then** "react" 칩이 다시 화면에 표시된다 (서버 원본 유지)

### 변경 파일

- `src/components/NoteEditor.tsx` (칩 컴포넌트에 `×` 버튼 추가, `removeTag` 와이어링)

## 이슈 3: 중복 태그 방지 (대소문자 무시)

### 설명

`useTagInput.addTag`에 중복 검증 로직을 추가한다. 비교는 `toLowerCase()` 기준이며, 저장값은 입력 원본 그대로 유지한다 (ADR-3.2 — "React" 입력 후 "react" 재입력 시 무시, "React"가 유지됨). 중복일 때 입력 필드는 비워지되 칩 목록은 변경되지 않는다.

### 완료 조건 (Acceptance Criteria)

**시나리오 1: 동일 casing 중복은 차단된다**
- **Given** 칩 목록에 "React"가 있고
- **When** 사용자가 "React"를 다시 입력하고 Enter를 누르면
- **Then** 칩 목록이 변하지 않고(여전히 1개) 입력 필드만 비워진다

**시나리오 2: 다른 casing 중복도 차단되고, 원본 표기는 보존된다**
- **Given** 칩 목록에 "React"가 있고
- **When** 사용자가 "react"를 입력하고 Enter를 누르면
- **Then** 칩 목록에 새 태그가 추가되지 않고, 기존 "React" 칩의 표기가 그대로 유지된다

### 변경 파일

- `src/hooks/useTagInput.ts` (addTag에 대소문자 무시 중복 검증 추가)

### 의존성

이슈 1

## 이슈 4: 노트당 최대 10개 태그 제한

### 설명

`useTagInput.addTag`에 개수 검증을 추가한다: `tags.length >= 10`이면 추가를 거부한다. 10개 도달 시 입력 필드를 비활성화하거나 시각적 피드백(placeholder 변경 등)을 제공해 사용자가 한도에 도달했음을 인지하게 한다. 시각 피드백은 디자인 시스템 토큰을 사용한다.

### 완료 조건 (Acceptance Criteria)

**시나리오 1: 10개 도달 시 추가가 차단된다**
- **Given** 칩 목록에 정확히 10개의 태그가 있고
- **When** 사용자가 11번째 태그 "extra"를 입력하고 Enter를 누르면
- **Then** 칩 목록은 여전히 10개이고 "extra"는 추가되지 않는다

**시나리오 2: 10개 도달 시 UI 피드백이 명확하다**
- **Given** 칩 목록에 9개의 태그가 있고
- **When** 사용자가 10번째 태그를 추가하면
- **Then** 입력 필드가 비활성화되거나 "더 이상 추가할 수 없음"이 명확히 드러나는 시각 상태로 전환된다

### 변경 파일

- `src/hooks/useTagInput.ts` (addTag에 개수 검증 추가)
- `src/components/NoteEditor.tsx` (입력 필드 비활성/플레이스홀더 변경)

### 의존성

이슈 1

## 이슈 5: 태그당 최대 20자 입력 제한

### 설명

입력 단계에서 즉시 차단해 사용자가 한도를 바로 인지하게 한다 (`<input maxLength={20}>`). 붙여넣기 등 우회 경로를 방어하기 위해 `addTag`에도 길이 검증을 둔다. 21자 이상 입력은 칩에 추가되지 않거나 20자로 절단되는 정책을 따른다.

### 완료 조건 (Acceptance Criteria)

**시나리오 1: 입력 단계에서 21자가 차단된다**
- **Given** 사용자가 태그 입력 필드에 포커스해 있고
- **When** "abcdefghijklmnopqrstu" (21자)를 입력하려고 시도하면
- **Then** 입력 필드에 최대 20자까지만 들어가고 마지막 글자는 무시된다

**시나리오 2: 붙여넣기 우회도 차단된다**
- **Given** 클립보드에 25자 문자열이 복사되어 있고
- **When** 사용자가 입력 필드에 붙여넣고 Enter를 누르면
- **Then** 칩 목록에 21자 이상의 태그가 추가되지 않는다 (최대 20자로 절단되거나 추가 거부)

### 변경 파일

- `src/components/NoteEditor.tsx` (input에 `maxLength={20}`)
- `src/hooks/useTagInput.ts` (addTag에 길이 방어 검증 추가)

### 의존성

이슈 1
