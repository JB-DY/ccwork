# 태그 기능 정의서 (확정)

## 기능 개요

노트에 태그를 추가하고 관리할 수 있다.

## 데이터 구조

`Note` 인터페이스에 `tags: string[]` 필드를 추가한다.

```ts
interface Note {
  id: string
  title: string
  content: string
  tags: string[]
  createdAt: string
  updatedAt: string
}
```

- 태그는 문자열 배열로 노트 객체에 인라인 저장
- `db.json`의 각 노트에 `tags` 필드 포함
- 기존 노트에 `tags` 필드가 없으면 빈 배열(`[]`)로 처리

## 기능 요구사항

### 태그 추가

- 노트 상세화면(NoteEditor)에 태그 입력창이 있다
- 입력창에 태그 텍스트를 입력하고 `Enter`를 누르면 태그가 추가된다
- 추가된 태그는 칩(badge) 형태로 입력창 위에 표시된다
- 태그 추가 후 입력창은 초기화된다

### 태그 삭제

- 각 태그 칩에는 `×` 버튼이 있다
- `×` 버튼을 누르면 해당 태그가 즉시 칩 목록에서 제거된다

### 태그 저장

- 태그 변경(추가/삭제)은 로컬 상태에만 반영된다
- 노트 저장 버튼 클릭 시 `title`, `content`와 함께 `tags`도 서버에 저장된다

## 엣지 케이스 및 제약

| 케이스 | 처리 방식 |
|--------|-----------|
| 중복 태그 | 동일 태그 무시 (대소문자 구분 없이 비교, 저장은 입력값 그대로) |
| 공백만 입력 | trim 후 빈 문자열이면 추가 무시 |
| 앞뒤 공백 | trim 후 저장 |
| 태그 내 공백 | 허용 (예: "hello world" → 하나의 태그) |
| 태그 최대 길이 | 20자 |
| 노트당 최대 태그 수 | 10개 |
